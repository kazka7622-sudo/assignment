# GitHub Assignment

## Introduction

GitHub is a platform used to store, manage, and share software projects. It helps developers track changes in their code and collaborate with other people.

## Purpose of GitHub

GitHub is used for:

- Storing code and project files
- Tracking changes in projects
- Collaborating with other developers
- Managing different versions of a project
- Sharing projects with others
- Building a developer portfolio

## Git vs GitHub

Git is a version control system that tracks changes in files.

GitHub is an online platform that hosts Git repositories and provides tools for collaboration.

## What I Learned

Through this assignment, I learned how to create a GitHub account, create a repository, edit a README file, and manage project files on GitHub.
